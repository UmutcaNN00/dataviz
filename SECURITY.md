# DataViz Güvenlik Politikası (Security Policy)

## Desteklenen Sürümler

DataViz projesinde güvenlik güncellemeleri aktif olarak ana dalda (`main`) sağlanmaktadır.

| Sürüm | Destek Durumu |
| :--- | :--- |
| 1.0.x (main) | :white_check_mark: Destekleniyor |
| < 1.0.0 | :x: Desteklenmiyor |

---

## Güvenlik Açığı Bildirimi

DataViz platformunda bir güvenlik açığı tespit ettiyseniz, lütfen bunu herkese açık bir GitHub Issue olarak **paylaşmayın**.

Güvenlik açıklarını bildirmek için:
1. GitHub deposundaki **Security** sekmesinden [Private Vulnerability Reporting](https://github.com/UmutcaNN00/dataviz/security/advisories/new) özelliğini kullanın.
2. Veya doğrudan proje geliştiricisine e-posta/iletişim yoluyla detaylı adımlar ve PoC (Proof of Concept) ile iletin.

### Bildirimde Yer Alması Gerekenler:
- Açığın türü ve etkisi (örn: SQL Injection, XSS, Path Traversal, DoS).
- Açığı tetikleyen örnek veri seti veya istek parametreleri.
- Varsa önerilen düzeltme veya geçici çözüm.

Bildirilen güvenlik açıkları en geç **48 saat** içinde incelenerek geri bildirim sağlanacaktır.
